# Sidebar brandmark → локализованная ссылка на главную — дизайн

**Дата:** 2026-07-22
**Статус:** дизайн утверждён, готов к плану

## Цель

Бренд-марка (лого + текст «ArchMentor») в шапке сайдбара (`src/app/Layout.tsx`) сейчас
не кликабельна. Делаем её ссылкой на `/` с локализованным `title`-тултипом.

## Решение

- Оборачиваем существующий блок лого+текст в `<Link to="/" title={t('common.home')}>`
  из `react-router-dom` (уже используется в файле для `NavLink`).
- Новый ключ `common.home` добавляется в оба блока (`ru`/`en`) `src/i18n/messages.ts`.
  Паритет ключей проверяется на этапе компиляции (`en` типизирован как
  `Record<MessageKey, string>`), так что забытый ключ — это ошибка `tsc`.
- Значения: ru — «ArchMentor — на главную», en — «ArchMentor — home».

## Область (scope)

- `src/i18n/messages.ts`: добавить `common.home` в `ru` и `en`.
- `src/app/Layout.tsx`: обернуть блок лого в `Link`.
- `src/app/App.test.tsx`: тест на `href="/"` и локализованный `title` для активной локали.

**Вне области:** остальная навигация, визуальный стиль, другие языки.
