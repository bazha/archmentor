# Концепт-карта (граф связей концептов) — дизайн

**Дата:** 2026-07-15
**Статус:** дизайн утверждён, готов к плану

## Цель

Новый режим **«Карта»** (`/map`): интерактивный граф всех 42 концептов, связанных по
полю `related`. Показывает то, чего нет ни в одном другом режиме — **структуру связей
между концептами** (семейства GoF, «часто путают», межкатегорийные связи). Пан/зум по
«карте архитектуры», клик по ноде → выделение соседей + боковая панель со ссылками в
Learn/Library. Переиспользует уже установленный React Flow.

## Область (scope)

- Новый роут/экран `/map` с графом на React Flow.
- Детерминированная раскладка нод кластерами по категориям (чистая функция, без новых
  зависимостей).
- Рёбра — union всех `related` (ненаправленно, без дублей).
- Клик по ноде: выделение + подсветка соседей + боковая панель.
- Полная обвязка: сайдбар, ⌘K, иконка.

Вне области: изменения схемы/контента/стора; прогресс-оверлей (освоенность на нодах);
force-directed раскладка; отдельный клавиатурный режим обхода графа (доступный эквивалент
уже есть — см. §a11y).

## Ключевые решения

- **Раскладка — детерминированная по категориям**, чистая функция (не force-directed).
  Без новой зависимости, стабильно, тестируемо, в духе проекта (`domain/*` чистые).
- **Рёбра — union `related`** (ребро, если A ссылается на B ИЛИ B на A), ненаправленно,
  без дублей. Богаче взаимных-только пар.
- **Клик → выделить + панель** (остаёшься на карте; исследование, а не просто навигация).
- **Без прогресс-оверлея** — цвет нод только по категории; граф остаётся чистой функцией
  контента (стор не нужен для рендера самого графа).

## Архитектура по единицам

### 1. Домен — `src/domain/graph/`

Чистый, framework-agnostic, тестируемый (как `srs`, `compare`, `daily`, `diagram`).

**Рёбра** — `src/domain/graph/edges.ts`:

```ts
export interface RelatedLike { id: string; related: string[] }
export interface ConceptEdge { a: string; b: string }
/** Union всех related-связей: ребро, если a упоминает b ИЛИ b упоминает a.
 *  Ненаправленно, каждая неупорядоченная пара один раз (a < b), детерминированная сортировка.
 *  Игнорирует ссылки на несуществующие id. */
export function selectConceptEdges(concepts: RelatedLike[]): ConceptEdge[];
```

Отличие от `compare/pairs.ts` (`selectConfusablePairs`) — там ВЗАИМНЫЕ пары; здесь UNION.
Оба существуют независимо.

**Раскладка** — `src/domain/graph/layout.ts`:

```ts
export interface CategoryLike { id: string; category: Category }
export interface NodePos { x: number; y: number }
/** Детерминированные позиции: кластер на категорию (центры по кольцу),
 *  концепты внутри кластера — по под-кольцу/сетке. Порядок категорий фиксирован
 *  (CATEGORY_ORDER), концепты сортируются по id. Чистая, детерминированная. */
export function layoutConcepts(concepts: CategoryLike[]): Record<string, NodePos>;
```

- Категории берём из фикс-списка `CATEGORY_ORDER = ['solid','creational','structural','behavioral','architecture','tradeoff']` — **определить в `layout.ts`** (готового `CATEGORY_ORDER` в проекте нет; в `lib/labels.ts` есть только `GRADE_ORDER` и `CATEGORY_LABEL`; референс порядка — enum `CategorySchema` в `schema.ts`).
- 6 категорий → 6 центров кластеров равномерно по окружности радиуса `R`.
- Внутри кластера: N концептов по под-окружности радиуса `r` (или сетке) вокруг центра, порядок по отсортированным id → детерминизм.
- Возвращает позицию для каждого id. Концепт без известной категории (не должно случаться — Zod-контент) кладётся в общий центр (безопасный дефолт).

### 2. Фича-экран — `src/features/map/`

- `Map.tsx` — роут-компонент. Строит React Flow `nodes` (из `layoutConcepts` + `useConcepts`
  для локализованных имён) и `edges` (из `selectConceptEdges`). `fitView`, pan/zoom,
  `<Controls>`, `colorMode={theme}` (как канва Diagram Builder). Держит `selectedId` в
  локальном состоянии.
- **Кастомная нода** — React-компонент: имя концепта, цвет/акцент по категории (токены
  `cat-*` через `Badge`-подобный дот или рамку). Тема наследуется от токенов.
- **Выделение:** при `selectedId` — инцидентные рёбра и соседние ноды подсвечены
  (className/стиль), остальные приглушены (opacity). Клик по ноде → `setSelectedId`.
- `ConceptPanel.tsx` — **отдельный компонент** (тестируется без React Flow):
  props `{ concept: ConceptView, onSelect: (id) => void }`. Показывает имя, бейджи
  категории (`Badge tone="category" category=…`) и грейда (`Badge tone="grade"`), tagline,
  чипы `related` (кнопки → `onSelect(relId)`), ссылки «Учить» (`/learn/:id`) и
  «В библиотеке» (`/library/:id`). Пустое состояние (ничего не выбрано) — краткая подсказка
  «Выбери концепт на карте».
- React Flow — только view-слой поверх той же чистой модели (ноды/рёбра/позиции).

### 3. Интеграция

- Роут `map` (lazy) в `src/app/App.tsx`, как остальные режимы.
- Пункт в `NAV` (`src/app/Layout.tsx`) + ветка в `titleKeyFor`.
- Запись в `SCREENS` (`src/components/CommandPalette.tsx`).
- Иконка `map` в `src/components/Icon.tsx` (добавить в `IconName` union + `PATHS`).
- i18n: `nav.map` + `map.*` (title, pickHint, learn, openLibrary, related, empty) в ru+en
  (`src/i18n/messages.ts`, паритет ключей). Бейджи категории/грейда переиспользуют
  существующие `CATEGORY_LABEL`/`GRADE_LABEL`.

Никаких изменений схемы, контента или стора.

### 4. a11y

React Flow-канва — визуальный слой; как канва Diagram Builder, она не полностью доступна с
клавиатуры и не тестируется в jsdom. Осознанное решение (не строим отдельный клавиатурный
режим обхода графа):

- **`ConceptPanel` и его чипы/ссылки полностью доступны с клавиатуры.** Выбрав концепт,
  можно обходить граф через чипы `related` (клик по чипу выбирает соседнюю ноду и обновляет
  панель) — доступная траверсия связей.
- **Эквивалентный доступный путь уже существует:** страницы Library перечисляют `related`
  как ссылки, а ⌘K позволяет прыгнуть к любому концепту. Карта — дополнительная
  визуализация, а не единственный путь к этой информации.
- Кнопки/ссылки/чипы имеют видимый focus-ring (существующие `focus-visible:ring-accent`).

### 5. Тесты

- **Домен** `src/domain/graph/edges.test.ts`: union (ребро при односторонней ссылке),
  дедуп неупорядоченных пар, ненаправленность, игнор ссылок на несуществующие id,
  детерминированная сортировка (по образцу `pairs.test.ts`).
- **Домен** `src/domain/graph/layout.test.ts`: у каждого концепта есть позиция; детерминизм
  (тот же вход → тот же выход); ноды разных категорий разнесены (центры кластеров различны);
  ноды одной категории сгруппированы рядом.
- **`ConceptPanel`** `src/features/map/ConceptPanel.test.tsx`: рендерит имя/tagline/бейджи;
  чипы `related` присутствуют и по клику вызывают `onSelect(relId)`; ссылки Learn/Library
  ведут на верные пути; пустое состояние при отсутствии выбора.
- **Экран** `src/features/map/Map.test.tsx`: смоук-маунт без краша (React Flow-канву в jsdom
  не гоняем — как канву Diagram Builder). Интеракция графа проверяется в браузере (CDP).

## Рассмотрено и отклонено

- **Force-directed раскладка** (dagre/d3-force) — новая зависимость + недетерминированные
  позиции (сложнее тестировать, «плавают»). Отклонено в пользу детерминированной по
  категориям.
- **Только взаимные рёбра** — теряет односторонние `related`-связи; **union выбран**.
- **Прогресс-оверлей** (освоенность на нодах) — отложено (YAGNI); цвет только по категории.
- **Ручные позиции в контенте** — ручной уход за 42 нодами; отклонено.

## Критерии готовности

- `/map` рендерит граф всех 42 концептов кластерами по категориям, рёбра — union `related`;
  pan/zoom/fitView; тёмная/светлая тема.
- Клик по ноде выделяет её + соседей и открывает `ConceptPanel`; чипы `related` переключают
  выбор; ссылки ведут в Learn/Library.
- Панель и её элементы доступны с клавиатуры; экран в сайдбаре, ⌘K, с иконкой; билингв.
- Домен (`edges`, `layout`) и `ConceptPanel` покрыты тестами; смоук-маунт экрана; все
  существующие тесты зелёные; tsc и build чистые.
