# n8n: PR merged → карточка в Done + коммент — дизайн

**Дата:** 2026-07-23
**Статус:** дизайн утверждён, готов к плану

## Цель

Замкнуть петлю доски: когда PR, открытый агентом по Trello-карточке, **смержен**, n8n
перемещает соответствующую карточку из **In Review** в **Done** и пишет коммент со ссылкой на
PR и на живой сайт. Сейчас карточка после мержа навсегда застревает в In Review.

Реализация — **отдельный n8n-воркфлоу**; изменений в репозитории **не требуется** (card id уже
зашит в имя ветки).

## Ключевые решения

- **Триггер — n8n GitHub Trigger** на `pull_request` репо `bazha/archmentor` (событийно; нода
  сама регистрирует webhook на репо, как Trello Trigger).
- **Card id из имени ветки:** агент называет ветки `trello/<card-id>-<slug>`; берём id из
  `pull_request.head.ref` регуляркой `trello/([0-9a-f]+)-`. Доп. маппинга PR↔карточка не нужно.
- **Фильтр:** только `action == "closed"` И `pull_request.merged == true` И `head.ref`
  начинается с `trello/` (не-мержи и не-агентские PR игнорируем).
- **«Задеплоено» = при мерже** (просто): коммент сразу на merge со ссылкой на сайт; ждать
  успеха deploy.yml не будем (деплой всё равно едет через пару минут).
- **Действия:** переместить карточку в **Done** + коммент `🤖 ✅ Смержено и задеплоено: <PR> •
  <site>`. Маркер `🤖` для единообразия (на Done-карточку логика возобновления не смотрит).
- **Отдельный воркфлоу** от Trello→dispatch — независимые триггеры, проще поддерживать.

## Архитектура (n8n-воркфлоу)
```
[GitHub Trigger]   pull_request на bazha/archmentor
      ▼
[Filter]           action="closed" && merged==true && head.ref начинается с "trello/"
      ▼
[extract cardId]   Set/Code: cardId = head.ref.match(/trello\/([0-9a-f]+)-/)[1]
      ▼
[Trello: move]     Card → Update: list = Done (DONE_LIST_ID)
      ▼
[Trello: comment]  Card Comment → Create: "🤖 ✅ Смержено и задеплоено: {prUrl} • https://bazha.github.io/archmentor/"
```
Trello-действия — через нативную **Trello-ноду** n8n (операции «Card: Update» для переноса и
«Card Comment: Create»), либо HTTP Request на Trello API (как в CI-скрипте). Trello-credential
в n8n уже есть.

## Предпосылки
- На доске список **Done** (создать, если нет) → его `list id` для ноды переноса.
- **GitHub-credential в n8n** для GitHub Trigger — токен с правом управлять вебхуками репо
  (fine-grained: Webhooks read/write + Metadata read; либо classic `repo` + `admin:repo_hook`).
  Нода сама создаст webhook на репо при активации.

## Поток данных
GitHub webhook (PR closed, merged) → n8n Filter (merged + trello/-ветка) → извлечь cardId из
`head.ref` → Trello move в Done + коммент со ссылкой на `pull_request.html_url` и сайт.

## Edge-cases
- **PR закрыт без мержа** → `merged==false` → фильтр отсекает (ничего не делаем). Возврат
  карточки при закрытии без мержа — вне области v1.
- **Не-агентский PR** (ветка не `trello/`) → отсекается фильтром.
- **Карточка уже в Done / удалена** → Trello-move вернёт ошибку; ставим ноду на
  «continue on fail», чтобы коммент/воркфлоу не падал жёстко.
- **Несколько PR на одну карточку** (дубли от тестов) → каждый merge двигает в Done
  (идемпотентно по смыслу).
- **Петля:** коммент с `🤖` не ре-триггерит (Done вне In Progress, а n8n commentCard-фильтр и
  так отсекает `🤖`).

## Тестирование
1. Смержить тестовый PR с веткой `trello/<id>-…` → в n8n Executions прогон; карточка `<id>`
   уезжает из In Review в **Done** + коммент со ссылкой.
2. Закрыть PR **без** мержа → воркфлоу не двигает карточку (фильтр).
3. Смержить не-`trello/` ветку (обычный PR) → игнор.

## Границы (v1)
Только merged→Done + коммент. Не обрабатываем: закрытие без мержа, ожидание успеха деплоя,
отражение статуса CodeRabbit, напоминания о застоявшихся PR (отдельные истории). Репозиторий
не меняется — вся логика в n8n + список Done.

## Критерии готовности
- Мерж агентского PR (`trello/*`) → карточка перемещается в Done с комментом со ссылкой на PR
  и сайт, событийно (n8n GitHub Trigger).
- PR без мержа и не-`trello/` PR — карточку не трогают.
- Ошибка переноса (нет карточки) не роняет воркфлоу.
- Изменений в репозитории нет; нужен лишь список Done и GitHub-credential в n8n.
