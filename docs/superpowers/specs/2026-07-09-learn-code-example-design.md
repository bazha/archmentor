# ArchMentor — Пример кода на флеш-карте (раздел «Учить»)

**Дата:** 2026-07-09
**Статус:** утверждён дизайн, готов к плану реализации
**Контекст:** приложение feature-complete, билингв RU/EN, clean-modern редизайн на master и в проде. Раздел «Учить» (`src/features/learn/Learn.tsx`) — колода флеш-карт (фильтр по грейду или одиночный концепт по маршруту `/learn/:conceptId`). Карта (`FlipCard`): лицо = имя концепта + tagline, оборот = определение + «Когда применять». У каждого концепта уже есть `codeExample` (`{ lang: 'typescript'; code; highlightLines? }`), локализованный в `ConceptView.codeExample`; он показывается на странице концепта (`ConceptPage`) через компонент `CodeBlock`, но в «Учить» не выводится.

## 1. Цель и рамки

Показать пример кода концепта на **обороте** флеш-карты через **прогрессивное раскрытие**: тумблер «Показать код», по клику раскрывающий пример инлайн. Карта остаётся компактной по умолчанию; код раскрывается осознанно. Переиспользует существующие `codeExample` и `CodeBlock` — без изменений данных/схемы.

### Не входит (YAGNI)
- Код на **лице** карты (режим «угадай паттерн по коду») — отложено; пересекается с квиз-режимом «Определи паттерн».
- Редактируемый/запускаемый код, подсветка diff и т.п.
- Изменения схемы или контента — `codeExample` уже есть у всех 42 концептов.
- Реальная 3D-анимация переворота — `FlipCard` остаётся как есть.
- Тумблер/код **внутри** лицевой разметки `FlipCard` (см. §3 — структурно нельзя без переработки FlipCard).

## 2. Поведение / UX

- Карта переворачивается как сейчас: лицо (имя + tagline) → оборот (определение + «Когда применять: …»).
- После переворота на оборот, **под картой** появляется тумблер **«Показать код»**. Клик раскрывает `CodeBlock` с `current.codeExample`; повторный клик — «Скрыть код» — скрывает.
- Код **скрыт по умолчанию** при каждом перевороте и при переходе к следующей карте: `showCode` сбрасывается в `false` на перевороте (`onFlip`) и в `next()`. Раскрытие всегда осознанное действие.
- Секция кода (тумблер + пример) отображается **только когда** `flipped === true` (код — часть ответа, не подсказка на лице).
- Работает одинаково в режиме колоды и в одиночном режиме (`/learn/:conceptId`).

## 3. Границы модулей / структура

**Ключевое решение:** тумблер и `CodeBlock` рендерятся **под** `FlipCard`, а не внутри него. `FlipCard` — это единственный `<button onClick={onFlip}>` (клик по всей карте переворачивает её). Вложенная `<button>` внутри `<button>` — невалидный HTML, и всплытие клика по тумблеру перевернуло бы карту. Размещение под картой сохраняет `FlipCard` нетронутым, избегает вложенности и даёт тот же UX (после переворота под картой появляется управление кодом).

| Единица | Ответственность |
|---|---|
| `src/features/learn/Learn.tsx` | состояние `showCode`; рендер `{flipped && <секция тумблер + опц. CodeBlock>}` между картой и кнопкой «Дальше»; сброс `showCode` в `onFlip` и `next()` |
| `src/i18n/messages.ts` | ключи `learn.showCode` / `learn.hideCode` (ru+en) |
| `src/components/CodeBlock.tsx` | без изменений — рендер `sample={current.codeExample}` |
| `src/components/FlipCard.tsx` | без изменений |

Новых компонентов и зависимостей нет.

## 4. i18n

- `learn.showCode`: «Показать код» / «Show code»
- `learn.hideCode`: «Скрыть код» / «Hide code»
- Обе локали, паритет ключей под существующим тестом (`en: Record<MessageKey, string>` + i18n-тест).

## 5. Доступность

- Тумблер — настоящий `<button type="button">` с `aria-expanded={showCode}` и `aria-controls`, указывающим на `id` регион-контейнера кода.
- Стиль тумблера — согласован с дизайн-системой (токены; вариант ghost/ссылочной кнопки с иконкой-шевроном `chevronRight`/`chevronLeft` из `Icon`).
- Клик по тумблеру не переворачивает карту (тумблер вне `FlipCard`, всплытия к `onFlip` нет).
- `reduced-motion` уже погашает переходы глобально; спец-анимация не требуется.

## 6. Тестирование

- **Новый тест** (`src/features/learn/Learn.test.tsx`): рендер → на лице карты тумблера кода нет; клик по кнопке `/перевернуть/i` (FlipCard) → появляется кнопка `/показать код/i`; клик по ней → рендерится текст из `codeExample` концепта (проверяемый фрагмент кода); повторный клик — код скрыт (кнопка снова «Показать код»).
- **Регрессия:** существующие Learn-тесты зелёные — кнопка `/перевернуть/i`, кнопка `/следующая/i`, текст «Определение» после переворота; счётчик не изменён.
- `tsc --noEmit` чист; весь набор зелёный; сборка без предупреждений; билингв RU/EN; обе темы.

## 7. Критерии готовности

- На обороте флеш-карты есть тумблер «Показать код»; клик раскрывает пример кода концепта через `CodeBlock`; повторный клик скрывает.
- Код скрыт по умолчанию и сбрасывается при перевороте карты и переходе к следующей.
- `FlipCard`, схема и контент не изменены; новых зависимостей нет.
- `tsc` чист, все тесты зелёные, билингв, обе темы.
