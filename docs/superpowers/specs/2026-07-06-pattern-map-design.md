# ArchMentor — Pattern Map (граф связей паттернов)

**Дата:** 2026-07-06
**Статус:** ОТЛОЖЕНО (2026-07-06) — дизайн утверждён, но реализация деприоритизирована в пользу «новых типов упражнений» (выше учебная ценность). Спека сохранена как будущая идея.
**Контекст:** приложение feature-complete, билингв RU/EN, гайдед-курс, на master и в проде. Каждый концепт имеет `related: string[]` — id родственных/«путаемых соседей» (Strategy↔State, Adapter↔Facade↔Proxy и т.п.), это ключевая педагогика приложения. Сейчас `related` показывается только текстовыми ссылками на странице концепта.

## 1. Цель и рамки

Добавить **глобальный интерактивный экран-карту** пространства паттернов: узлы = 42 концепта, рёбра = связи `related`. Даёт обзор всего пространства и наглядно показывает кластеры «путаемых соседей». Раскладка — **кластеры по категориям** (выбор пользователя из визуального сравнения). Клик по узлу → страница концепта; hover/focus подсвечивает соседей.

### Не входит (YAGNI)
- Force-directed раскладка и любая рантайм-физика/анимация симуляции (раскладка детерминированная).
- Редактируемый code-playground, «отрефактори код», UML-диаграммы — отдельные будущие фичи (эта итерация — только граф связей).
- Мини-граф на странице концепта — рассматривался, отложен; здесь только глобальный экран.
- Готовые graph-библиотеки (d3/reactflow/vis) — нарушают принцип «без новых тяжёлых зависимостей»; рисуем на чистом SVG.
- Новый персист-слайс/бэкенд — граф строится из уже существующих данных.

## 2. Модель графа (данные)

Чистая функция `buildGraph(concepts: Concept[]): { nodes: GraphNode[]; edges: GraphEdge[] }`:
- `GraphNode = { id: string; name: string; category: Category }` — из общих (не локализованных) полей концепта.
- `GraphEdge = { a: string; b: string }` — **неориентированный union** поля `related`: для каждой пары (c.id, r∈c.related) берём канонический ключ `[c.id, r].sort().join('|')`, дедуп. При текущих данных — 95 рёбер (`related` наполовину односторонний; union убирает дубли и делает рёбра симметричными).
- Никаких новых данных: только `id`, `name`, `category`, `related` — все общие поля.

## 3. Раскладка (детерминированная, без физики)

`src/features/map/layout.ts` — чистая `layout(concepts): Record<id, {x, y}>`:
- 6 категорий в порядке `['solid','creational','structural','behavioral','architecture','tradeoff']` раскладываются в сетку зон **3 колонки × 2 ряда**.
- Каждой зоне — прямоугольная область фиксированного размера в `viewBox` (напр. 960×640 → зоны ~300×300 с отступами).
- Внутри зоны узлы категории пакуются в мини-сетку: `cols = ceil(sqrt(N))`, ряды по необходимости; позиция узла = начало зоны + смещение по (индекс в категории). Behavioral (11 узлов, максимум) свободно влезает.
- Позиция = чистая функция (индекс категории, индекс узла в категории). Без seed, без итераций, без анимации → детерминированно и тестируемо.

## 4. Экран (`src/features/map/Map.tsx`, чистый SVG)

- `<svg viewBox=...>` со слоями: (1) фоны зон — скруглённые прямоугольники + подпись `CATEGORY_LABEL[lang][category]`; (2) рёбра — линии между позициями узлов (внутри зоны сплошные, между зонами пунктирные/светлее); (3) узлы — кружки, цвет = категория.
- Каждый узел — **фокусируемая ссылка** (react-router `<Link>` внутри SVG через `<a>`/обёртку, `tabIndex`) на `/library/:id`; `aria-label` = имя концепта (доступное имя есть всегда, независимо от меток).
- **Hover/focus узла** → подсветка узла и его соседей (повышенная непрозрачность), остальные узлы и не-инцидентные рёбра гаснут (снижение opacity). Так управляется плотность 95 рёбер.
- **Метки:** имена показываются при hover/focus (у наведённого узла и его соседей); в покое — точки + цвет категории (42 полных имени засорили бы полотно). Полные имена доступны через `aria-label` и клик.
- **Легенда** категорий (цвет → `CATEGORY_LABEL[lang]`).
- **Адаптив:** SVG `max-width:100%` с сохранением пропорций; обёртка `overflow-x-auto` с `min-width`, чтобы на узком экране карта оставалась читаемой и скроллилась по горизонтали.

## 5. Цвета категорий

`src/features/map/colors.ts` — `CATEGORY_COLOR: Record<Category, string>`: 6 различимых цветов (напр. indigo/emerald/amber/pink/sky/violet-семейство), подобранных так, чтобы кружок-узел был различим на канве и в светлой, и в тёмной теме (графический объект → порог контраста ≥3:1 к фону канвы; проверить расчётом). Канва/зоны/рёбра — через семантические токены (`surface`, `surface-muted`, `muted`); подсветка — `accent`. Метки — `text-content`.

## 6. Маршрут, навигация, i18n

- Ленивый маршрут `/map` в `app/App.tsx` (тот же паттерн `lazy: () => import(...).then(m => ({ Component: m.Map }))`).
- Навпункт «Карта»/«Map» в `app/Layout.tsx` (через `t('nav.map')`).
- Ключи в `src/i18n/messages.ts` (обе локали, паритет под стражем теста): `nav.map` (Карта/Map), `map.title` (Карта паттернов/Pattern map), `map.hint` (Наведите на узел, чтобы увидеть связи; клик — открыть концепт / Hover a node to see its links; click to open the concept).
- Данные графа — из сырых `concepts` (общие поля `id/name/category/related`); имена узлов английские (общие), подписи зон/легенды локализованы.

## 7. Тема, доступность

- Тема: семантические токены для канвы/зон/рёбер/подсветки; категорийные цвета — из `colors.ts`, легибельны в обеих темах.
- Доступность: узлы — фокусируемые ссылки с `aria-label` (клавиатурная навигация Tab, Enter → переход); рёбра декоративны (`aria-hidden`); focus даёт ту же подсветку, что hover. `prefers-reduced-motion` гасит opacity-переходы. Контраст меток — `text-content` (под охраной `contrast.test.ts`).

## 9. Тестирование

- **`layout.test.ts`**: `buildGraph` — рёбра = неориентированный union без дублей (95 при текущих данных), симметрия (для ребра {a,b} нет обратного дубля {b,a}); каждый узел присутствует; `layout` — каждому из 42 концептов назначена позиция, и позиция лежит в границах зоны своей категории; детерминизм (один вход → один выход).
- **`Map.test.tsx`** (детерминированный язык): рендерит все 42 узла и рёбра; узел — ссылка на `/library/:id` с доступным именем; hover/focus узла подсвечивает его соседей (проверка класса/opacity или data-атрибута); подписи зон в RU и один прогон EN; легенда присутствует.
- **a11y**: у узлов есть доступные имена (`getByRole('link', { name })`).
- Регрессия: весь текущий набор зелёный; `tsc --noEmit` чист; `npm run build` без предупреждений.
